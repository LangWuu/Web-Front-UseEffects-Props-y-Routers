# Web-Front-UseEffects-Props-y-Routers
Aqui se subieron todas las tareas juntas en un mismo proyecto
Se utiliza:
* useState	TaskForm.jsx, TasksContext.jsx
* useEffect con cleanup	Clock.jsx, Quote.jsx, useDebounce.js, useWindowWidth.js, useDocumentTitle.js
* useContext	ThemeContext.jsx, TasksContext.jsx
* Enrutamiento SPA	App.jsx, Layout.jsx, TaskDetail.jsx, Tasks.jsx
* Patrones de props	Card.jsx (children), List.jsx (render prop), TaskItem.jsx (callbacks), Button.jsx (spread )
